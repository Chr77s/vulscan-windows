Authentification (scan post-login)

Pour scanner les pages derrière une authentification, fournis ici les informations de session. Les modules réutiliseront ces credentials sur chaque requête.
Astuce : connecte-toi à la cible dans un autre onglet, ouvre DevTools → Application → Cookies, copie la valeur du cookie de session.

Backend Python (REQUIS)

Le backend Python est nécessaire pour que le scan fonctionne pleinement. Il fournit :
  • la lecture des vrais en-têtes HTTP (CSP, HSTS, X-Frame-Options) — impossible côté navigateur
  • la vérification CVE des bibliothèques détectées
  • la corrélation bayésienne des signaux pour réduire les faux positifs
Démarrage : double-clic sur backend/start.bat (Windows) ou ./start.sh (Mac/Linux).
